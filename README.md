# Trading App - Crypto & Stock Trading Platform

🚀 A full-stack trading application built with React, Node.js, Express, and PostgreSQL.

## Features

✅ **User Authentication** - Secure login/register with JWT
✅ **Real-time Market Data** - Live crypto prices 
✅ **Trading System** - Buy/Sell cryptocurrencies
✅ **Portfolio Management** - Track your holdings
✅ **Trading History** - View all transactions
✅ **Responsive UI** - Works on all devices

## Tech Stack

- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express + PostgreSQL
- **Authentication**: JWT
- **Real-time**: CoinGecko API

## Quick Start

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Database
```bash
psql -U postgres < backend/schema.sql
```

## Deployment

- Frontend: Deploy to Vercel
- Backend: Deploy to Render.com
- Database: Render PostgreSQL
